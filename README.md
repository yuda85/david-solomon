אתר HTML סטטי (בלי שרת ובלי כלי בנייה) — מוכן לעלות ל־GitHub Pages כמו שהוא.

## מבנה

| כתובת | עמוד |
|---|---|
| `/` | עמוד הבית — שלושה כיוונים: טיפול / ארגונים / תוכן |
| `/about/` | אודות |
| `/therapy/` | טיפול וקליניקה |
| `/trauma/` | טיפול בטראומה ובפוסט־טראומה |
| `/lectures/` | הרצאות, סדנאות והנחיית קבוצות |
| `/organizations/` | ארגונים ומסגרות |
| `/content/` | תוכן, פודקאסטים וסרטונים |
| `/contact/` | יצירת קשר + טפסים |

```
assets/css/style.css        העיצוב
assets/js/site-config.js    רשתות חברתיות + סרטונים  ← הקובץ שעורכים הכי הרבה
assets/js/main.js           תפריט, טפסים, סרטונים
assets/img/                 תמונות (WebP, מוקטנות)
_src/                       מקור העמודים + סקריפט בנייה (GitHub Pages מתעלם מהתיקייה)
```

## העלאה ל־GitHub Pages

1. יוצרים ריפו חדש ב־GitHub (למשל `david-solomon`).
2. מתיקיית האתר:

```bash
git init -b main
```

```bash
git add .
```

```bash
git commit -m "האתר של דוד סולומון"
```

```bash
git remote add origin https://github.com/<USER>/david-solomon.git
```

```bash
git push -u origin main
```

3. ב־GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save.
4. אחרי דקה־שתיים האתר עולה בכתובת `https://<USER>.github.io/david-solomon/`.

> התמונות המקוריות מוואטסאפ ומסמך החזון מוחרגים ב־`.gitignore` ולא יעלו.

## עריכת תוכן

אפשר לערוך את קבצי ה־HTML ישירות.
אבל אם משנים משהו שחוזר בכל העמודים (תפריט, כותרת תחתונה, טפסים, טלפון), עדיף לערוך את המקור ב־`_src/` ולהריץ:

```bash
python _src/build.py
```

הסקריפט בונה מחדש את כל העמודים. **שימו לב:** הוא דורס את קבצי ה־HTML — שינוי שנעשה ישירות ב־HTML צריך להיעשות גם ב־`_src/pages/`.

## דומיין משלכם (אופציונלי)

1. ב־GitHub: Settings → Pages → Custom domain.
2. ב־`_src/build.py` מעדכנים `SITE_URL = "https://הדומיין"` ומריצים build — זה משפר את התצוגה המקדימה כששולחים קישור בוואטסאפ.
